# Expense Splitter

A MERN stack app to split expenses among friends fairly.

## Status

🚧 In development — v1 in progress

## Problem

Groups of friends struggle to track shared expenses and settle debts fairly. Manual math causes errors and awkward conversations.

## Tech Stack

- **Frontend:** React + Vite
- **Backend:** Node.js + Express
- **Database:** MongoDB Atlas
